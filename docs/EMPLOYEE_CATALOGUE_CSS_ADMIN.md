# Superseded: PostgreSQL Employee Catalogue projection

This former Store integration design used CSS Admin PostgreSQL for Employee Catalogue Role snapshots. It is superseded by [EMPLOYEE_CATALOGUE_LIVE_MODE.md](EMPLOYEE_CATALOGUE_LIVE_MODE.md), which reads the assigned Magento Employee company role directly.
